## [0.1.0] - 2026-11-10

### Added

- Concept, data model, risk score, audience views, visual rules and build plan in `docs/`.
- Five display styles (trading card, broadcast scoreboard, RPG character sheet, wallet stack, roster heatmap) as a self-contained static mockup in `mockups/index.html`, with source in `mockups/src/`.
- Build prompts for each style and a shared backend prompt in `prompts/`.
- `AGENTS.md` contributor rules for testing, operational instrumentation, documentation and security.
- Community files, ADR 0001, issue and pull request templates, and a docs CI workflow.
